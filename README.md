## MotorPH Employee App (Computer Programming 2 – MOIT103 Group 22)

A Java Swing-based payroll management system developed for MotorPH that automates employee payroll computation. The application calculates mandatory government deductions such as SSS, PhilHealth, Pag-IBIG, and withholding tax while providing payroll processing and employee record management features.

\### Key Features

\* Secure login system for both payroll staff and employee users

\* Employee profile and information viewing

\* Payroll generation for individual employees

\* Batch payroll processing for all employees

\* CSV-based employee and attendance record handling

\* Integrated 2024 SSS contribution rate calculations

\* Automatic computation of PhilHealth, Pag-IBIG, and withholding tax deductions

\### How to Run the Application

1\. Open the project using Apache NetBeans IDE.

2\. Make sure the files `mph\_employees\_record.csv` and `attendance\_record.csv` are placed in the project’s root directory.

3\. Press `F6` to build and run the application.

\### Sample Login Credentials

\* `payroll\_staff / 12345` — access to payroll management features

\* `employee / 12345` — access to employee information only

\### Technologies Used

\* Java Development Kit (JDK) 25

\* Java Swing for the graphical user interface

\* Apache NetBeans IDE for development
